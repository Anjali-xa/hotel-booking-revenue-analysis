# Hotel Booking & Revenue Analysis

Analyze booking demand, cancellation behaviour, occupancy patterns, and revenue performance.

## 🎯 Project Objectives
- Prepare and validate the dataset before analysis.
- Explore trends, distributions, and key performance indicators.
- Answer practical business questions with reproducible analysis.
- Communicate findings through clear tables and visualizations.

## ❓ Business Questions
- When is booking demand highest?
- Which segments cancel more often?
- How do lead time and seasonality relate to revenue?

## 🧰 Tools & Technologies
- Excel
- SQL
- Python
- Power BI

## 📊 Dataset
**Suggested source:** [Hotel Booking Demand dataset (Kaggle); confirm access and licence before reuse](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)

The dataset has not yet been added to this repository. Before analysis, document the exact download page, licence, date range, column definitions, and any filtering or cleaning performed. Do not treat sample or synthetic records as real-world findings.

1. Acquire the dataset and record its source and licence.
2. Inspect data types, missing values, duplicates, and outliers.
3. Clean and transform the data with documented steps.
4. Use SQL and Python/Excel for analysis and KPI calculations.
5. Build a Power BI dashboard where applicable.
6. Summarize evidence-based insights and limitations.
